## CN2 GIA-E 是什么，和 CN2 GIA 有什么区别

搬瓦工对这两个名词的使用会把新手搞迷糊。简单说：

**CN2 GIA**，指 DC9 机房（洛杉矶 USCA\_9），纯粹的电信 CN2 GIA 线路，AMD EPYC 处理器，NVMe SSD，三网回程都走 CN2 GIA。

**CN2 GIA-E**（E 代表 Ecommerce，"电子商务"），指 DC6 机房（洛杉矶 USCA\_6），同样是 CN2 GIA 级别线路，但对应的套餐可以切换到更多机房，包括 DC6、DC9、日本大阪软银、荷兰联通9929 等 12+ 个机房。这就是 GIA-E 套餐最核心的卖点——买一个套餐，等于拿到了一张多机房的通行证。

带宽上也有差异：CN2 GIA-E 套餐从 2.5Gbps 起步，高配可达 10Gbps；而普通 CN2 套餐带宽通常为 1Gbps。
